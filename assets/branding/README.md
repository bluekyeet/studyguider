# StudyGuider branding

`icon.png` and `wordmark.png` are the user-supplied originals, moved from `docs/`.
Keep these originals intact. Website-sized PNGs live in `server/branding/`;
Android launcher sizes live in `android/app/src/main/res/mipmap-*/`.

The wordmark derivative crops the original background to its central artwork.
The README uses that derivative as its repository banner. GitHub's repository
social-preview image is a separate repository setting, not configured by these files.
